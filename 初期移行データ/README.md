# Live setlist JSON files

Generated: 2026-09-19

- One JSON file per attended concert/festival date.
- Festival files contain only the artists confirmed as attended in the referenced conversation.
- `position` is continuous within each file; artist-local order and phase are preserved in `notes`.
- `key`, `duration`, and `energy` are `null` because no reliable evidence was available.
- Rehearsals and encores are included only when confirmed and are labeled in each song's `notes`.
- Unknown or conflicting DAIENKAI data is not guessed; omissions/uncertainty are explained in `setlist.notes`.

## Principal sources

- Prior conversation and user-supplied images (attendance selections and ヤバT 2026-08-25)
- ROCK IN JAPAN / VIVA LA ROCK official live reports
- Artist official posts/pages where available
- ソノダマン (@yoppeleah) FC2 live reports for DAIENKAI 2025/2026
- LiveFans and event/attendee reports for incomplete DAIENKAI 2024 data
